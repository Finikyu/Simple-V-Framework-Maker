# Simple V Framework Maker

Simple V Framework Maker turns your Metal Gear Solid V: The Phantom Pain mods into V Framework mods. It works with outfits, heads, weapons, grenades and buddy costumes. You can also change mods that already use V Framework.

The app makes one .mgsv file. You install it with SnakeBite or Diamond Mod Manager, as you install other mods.

Version 0.2.2 is an early test version. Some functions are not tested in the game yet.

## What you need

- Metal Gear Solid V: The Phantom Pain on PC.
- SnakeBite or Diamond Mod Manager.
- To play the mods that you make: V Framework 1.7, Infinite Heaven and IHHook.

V Framework: https://github.com/Yazed0071/V_Framework
V Framework guide: https://mgsvmoddingwiki.github.io/V_Framework/

## Start the app

1. Download the zip file from the Releases page and extract it.
2. Put the SimpleVFrameworkMaker folder in a place where it can stay, for example your Documents folder. Do not start the app from inside the zip.
3. Double-click SimpleVFrameworkMaker.exe.
4. Windows can show "Windows protected your PC". If you trust this download, click "More info". Then click "Run anyway".
5. The first time, the app asks for your game folder. This is the folder that has the "master" folder in it.

## Make a mod

1. Click "Choose a file" and open a mod (.mgsv or .zip).
2. Click "Continue to setup".
3. Change what you want: names, descriptions, icons, abilities, camo and R&D values.
4. Click "Review & build". Then click "Build".
5. Install the new .mgsv file with SnakeBite or Diamond Mod Manager.

To continue later, click Save. Open the saved project file (.svfm) next time.

## Report a problem

1. Click Help > "Save problem report". You can also click "Save problem report" on the red error message.
2. The app saves a text file next to the exe and opens a form on GitHub.
3. Attach the text file to the form. Tell what you did and what went wrong.

The app does not send anything by itself. Your Windows user name is not in the report.

Problem form: https://github.com/Finikyu/Simple-V-Framework-Maker/issues/new?template=problem.yml
